# Vesper Parfums

An elegant, interactive perfume e-commerce website concept inspired by the fragrances and atmosphere of Fort Kochi, Kerala.

## 🌿 Project Overview

Vesper Parfums is a premium perfume brand website featuring an immersive design, smooth animations, interactive fragrance selections, and a modern shopping experience.

The website is designed as a portfolio project to demonstrate modern frontend development and UI/UX design skills.

## ✨ Features

- **Interactive Hero Section** – Animated perfume bottle with floating effects.
- **Fragrance Selection** – Three fragrances: Midnight, Ember, and Verdant.
- **Dynamic Theme Switching** – Website colors change based on the selected fragrance.
- **Animated Storytelling** – Interactive fragrance notes and scrolling animations.
- **Product Details** – Top, heart, and base fragrance notes.
- **Multiple Product Sizes** – 30 ml, 50 ml, and 100 ml options.
- **Shopping Bag** – Add and remove products with automatic price calculation.
- **Fragrance Quiz** – Helps visitors discover their preferred fragrance.
- **Wear Performance** – Displays fragrance longevity and projection.
- **Customer Reviews** – Sample testimonial section.
- **Visual Gallery** – Editorial perfume photography.
- **Sample Request Form** – Interactive demo contact form.
- **Responsive Design** – Optimized for desktop, tablet, and mobile.
- **Mobile Navigation** – Dedicated full-screen mobile menu.
- **Accessibility** – Keyboard
